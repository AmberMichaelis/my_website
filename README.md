# KrustyKrab Website

This is my first website ever, [KrustyKrab.us](www.krustykrab.us)!

A collection of games, experiments, coding projects, animations, and occasionally questionable decisions.

## Overview

The KrustyKrab Website is a personal playground created by Amber Michaelis while learning software development. Rather than focusing on a single application, the site serves as a collection of projects built over several years of experimentation with HTML, CSS, JavaScript, Node.js, animation, UI design, and web development.

Some projects were created as learning exercises. Others were built simply because they seemed fun.

The result is a website that combines technical projects, interactive experiences, hidden pages, custom animations, coding challenges, and a few intentionally ridiculous features.

## Features

### Custom Animations

Hand-built animations created without relying on major animation frameworks or libraries.

### Browser Games

Interactive games developed using vanilla JavaScript to practice programming concepts, event handling, rendering, game loops, and user interaction.

### Claudius Chatbot

A custom chatbot project designed as an experiment in conversational interfaces and web development.

### LeetCode Solutions

A collection of algorithm and problem-solving exercises used to improve programming skills and interview preparation.

### Testimonials

A completely trustworthy collection of testimonials that should absolutely be taken seriously.

Probably.

### Secret Areas

Hidden pages, Easter eggs, and various surprises scattered throughout the site.

### Self-Destruct System

Every respectable website should have one.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js

## Purpose

The primary purpose of this project is learning.

The website documents the process of becoming a software developer by building real projects, experimenting with new ideas, and occasionally creating things simply because they are entertaining.

While some sections are polished and others are clearly products of experimentation, each project represents a step in the learning process.
